ufw allow from  to any port 22  # Peer sync via rsync

How to Get an OpenRouter Key

  1. Go to openrouter.ai
  2. Sign up / log in
  3. Go to Keys → Create Key
  4. Name it serverroot-prod
  5. Add credits ($5–$20 for extensive use)
  6. Copy the key (starts with sk-or-v1-...)
  7. Add to .env: OPENROUTER_API_KEY=sk-or-v1-...
  8. Restart services: bash deploy/start_all.sh
💡 Cost estimate: ~$0.001–0.01 per AI operation. $10 credit = thousands of exploit analyses.

Setting the API Key (once you have it)

# On each VM, edit /opt/serverroot/.env:
nano /opt/serverroot/.env

# Add/update this line:
OPENROUTER_API_KEY=sk-or-v1-your-key-here

# Restart services to pick it up:
systemctl restart serverroot-api
# OR (dev environment):
bash deploy/start_all.sh
